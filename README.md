# SMS Activate Bot

Telegram-бот для продажи виртуальных номеров под приём СМС. Номера закупаются через API
[Grizzly SMS](https://grizzlysms.com) и продаются клиентам с наценкой (по умолчанию ×2).

## Возможности

- Языки: 🇷🇺 русский, 🇬🇧 английский, 🇹🇲 туркменский.
- Покупка номера: популярные сервисы, все сервисы, поиск по названию, страны отсортированы по цене.
- Код из СМС приходит автоматически. Есть кнопки «Ещё СМС», «Завершить», «Отменить» и копирование номера и кода.
- Если СМС не пришло за `ORDER_TIMEOUT_MIN` минут, номер отменяется и деньги возвращаются на баланс.
- Пополнение баланса:
  - **CryptoBot**: USDT, TON, BTC, ETH и другие, счёт выставляется в рублях;
  - **Telegram Stars**;
  - **банковская карта в рублях** через платёжного провайдера Telegram (ЮKassa и др.).
- Цветные кнопки: зелёные, синие и красные.
- Премиум-эмодзи в тексте сообщений и на кнопках.
- Админ-панель: статистика и прибыль, баланс Grizzly, рассылка, бан и разбан, начисление баланса,
  смена наценки и курсов, настройка эмодзи.

## Установка одной командой

Подходит сервер (VPS) с Ubuntu 22.04+ или Debian 12+. Выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/SmsActivateBot/HEAD/install.sh | sudo bash
```

Скрипт сам:

- поставит Python и git;
- скачает бота в `/opt/smsbot`;
- задаст вопросы о токенах и ключах;
- включит автозапуск, чтобы бот работал 24/7 и после перезагрузки сервера.

Если репозиторий приватный, добавьте токен GitHub:

```bash
curl -fsSL -H "Authorization: token ВАШ_ТОКЕН" \
  https://raw.githubusercontent.com/k9032431-cmd/SmsActivateBot/HEAD/install.sh \
  | sudo GITHUB_TOKEN=ВАШ_ТОКЕН bash
```

## Обновление одной командой

```bash
sudo smsbot update
```

Команда скачает новую версию, обновит зависимости и перезапустит бота. Настройки (`.env`)
и база данных с балансами клиентов сохраняются. Перед обновлением база копируется в `bot.db.bak`.

## Управление

| Команда | Что делает |
|---|---|
| `sudo smsbot update` | обновить до последней версии |
| `sudo smsbot config` | изменить настройки (`.env`) и перезапустить |
| `sudo smsbot restart` / `start` / `stop` | перезапустить, запустить или остановить |
| `sudo smsbot status` | статус |
| `sudo smsbot logs` | логи в реальном времени |
| `sudo smsbot backup` | резервная копия базы в `/opt/smsbot/backups` |

### Ручной запуск (для разработки)

```bash
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните файл
python -m bot
```

### Что заполнить в `.env`

| Переменная | Где взять |
|---|---|
| `BOT_TOKEN` | @BotFather → `/newbot` |
| `ADMIN_IDS` | ваш Telegram ID (@userinfobot) |
| `GRIZZLY_API_KEY` | grizzlysms.com → Кабинет → Настройки → API-ключ |
| `GRIZZLY_CURRENCY` | `RUB` или `USD`: в какой валюте баланс аккаунта Grizzly |
| `CRYPTOPAY_TOKEN` | @CryptoBot → Crypto Pay → Create App → API Token |
| `PAYMENT_PROVIDER_TOKEN` | @BotFather → бот → Payments → провайдер (ЮKassa и т.п.) |
| `STAR_RUB_RATE` | сколько рублей засчитывать за 1 ⭐ |

Если для способа оплаты не указан токен, этот способ просто не показывается.

Важно: бот покупает номера с **вашего** баланса в Grizzly, поэтому держите его пополненным.
Когда деньги там закончатся, бот пришлёт админам предупреждение.

## Премиум-эмодзи

У владельца бота должен быть Telegram Premium. Все эмодзи в текстах и на кнопках бота можно
заменить на премиум, включая логотипы сервисов (`svc_tg`, `svc_wa` …) на кнопках.

**Целый пак одной командой.** Найдите пак премиум-эмодзи (ссылка вида `t.me/addemoji/Название`)
и отправьте боту:

```
/emojipack https://t.me/addemoji/Название
```

Бот сам подберёт эмодзи из пака под каждое место (🛒 → покупка, 💰 → баланс и т.д.).

**Вручную**, одной строкой или сразу списком:

```
/setemoji buy 🛒
wallet 💰
phone 📱
```

- `/emojis` — все места и текущие эмодзи (⭐ — уже премиум);
- `/delemoji имя` — вернуть обычный эмодзи, `/delemoji all` — сбросить все.

## Баннер

Главное меню показывается картинкой с подписью. По умолчанию бот сам рисует баннер с названием
из `BOT_NAME`. Посмотреть его заранее: `python -m bot.banner "Название"`.

Поставить свой баннер (картинку или GIF): отправьте боту фото или GIF с подписью `/setbanner`.
Вернуть стандартный баннер: `/delbanner`. Лучший размер — 1280×640.

## Команды админа

`/admin` — панель
`/user ID` — информация о пользователе
`/addbal ID сумма` — начислить или списать баланс
`/ban ID`, `/unban ID`
`/setmarkup 2` — наценка
`/setstar 1.8` — курс звезды
`/setusd 95` — курс доллара (нужен, если баланс Grizzly в $)
